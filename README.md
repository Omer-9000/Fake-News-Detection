📰 Fake News Detection System

This project aims to detect fake news articles using NLP techniques and SBERT embeddings, providing users with accurate predictions and relevant fact-checked articles for verification.

📌 Features

Real-time Fake News Detection using a pre-trained Sentence-BERT (SBERT) model and ML classifier.

Cosine Similarity Search to find related fact-checked articles from trusted sources.

Interactive Web Interface built with Streamlit for easy access.

SBERT embeddings for robust text representation.

High Accuracy Model trained on a balanced dataset of real and fake news.

🧪 Tech Stack

Python 3.10+

Sentence-BERT (all-MiniLM-L6-v2)

scikit-learn (Logistic Regression)

Streamlit (for web app)

BeautifulSoup & Selenium (for scraping articles)
